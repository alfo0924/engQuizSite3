## 網站特色介紹

這個「QuizMaster 英文文法測驗」網站是一個專為多益（TOEIC）與托福（TOEFL）常見文法題型設計的線上測驗平台，重點特色如下：

- **針對多益/托福常見文法題型**：題庫涵蓋動詞變化、假設語氣、介系詞、主謂一致、關係代名詞、被動語態、連接詞、比較級、所有格、不定詞、形容詞等，符合真實考試需求。
- **25題選擇題，4選1**：每題皆有解析與加強建議，幫助用戶了解錯誤原因並針對弱點學習。
- **扁平化現代設計**：採用明亮配色、簡潔線條、充足留白，符合現代UI/UX設計趨勢，頁面易於閱讀與操作。
- **響應式設計**：手機、平板、桌機皆適用，確保各類裝置體驗一致。
- **即時回饋與分數預估**：送出後立即顯示正確題數，並根據正確率自動換算多益與托福預估分數（如「18/25（多益估分: 730，托福估分: 93）」）。
- **逐題解析與建議**：每題作答後，正確或錯誤的解析與加強建議直接顯示於該題下方，方便用戶即時檢討。
- **錯誤類型統計與總結**：分數區塊會統計需加強的文法類型，並給予中文建議。
- **全繁體中文介面**：題目、解析、建議、操作提示皆為繁體中文，降低學習門檻。
- **流程簡單直覺**：一頁式作答，送出後所有資訊一目了然，無需切換頁面或重複操作。

此設計理念與許多現代線上英文文法學習工具（如Grammarly、Wordvice AI、Virtual Writing Tutor等）強調即時回饋、錯誤解析與用戶友善介面相呼應[1][2][3][5]。

## 程式碼原理與邏輯說明

### 1. 題庫資料結構

- 題庫以陣列（Array）儲存，每一題為一個物件（Object），包含題目、選項、正確答案索引、解析說明、錯誤類型等欄位。
- 錯誤類型（如「動詞變化」、「假設語氣」等）用於後續分析與建議。

### 2. 頁面渲染與互動

- **動態產生題目**：JS程式於網頁載入時，根據題庫動態建立每一題的HTML結構，包含題目文字、四個選項（radio button），以及預留的解析區塊。
- **響應式設計**：CSS採用扁平化風格與媒體查詢，確保不同裝置皆有良好閱讀體驗。

### 3. 作答與送出流程

- 用戶於表單中逐題作答，所有選項皆為單選（radio）。
- 按下「送出答案」後，JS會：
    - 逐題檢查用戶選擇，與正確答案比對。
    - 記錄每題作答結果（正確/錯誤、選擇答案、錯誤類型）。
    - 統計正確題數。

### 4. 分數計算與預估

- **正確題數計算**：統計答對題數。
- **多益/托福分數換算**：根據正確率，將得分線性對應到多益10~990分、托福10~120分的區間，顯示於分數區塊。
- **錯誤類型統計**：統計用戶答錯的文法類型，於分數區塊給出需加強的建議。

### 5. 逐題即時解析

- 每題下方的解析區塊在送出後動態填入內容：
    - 答對：顯示「✔ 正確」。
    - 答錯：顯示「✘ 錯誤」、用戶答案、正確答案、中文解析、加強建議。
- 解析區塊配合正確/錯誤以不同顏色呈現，視覺上易於判讀。

### 6. UI/UX設計原則應用

- **狀態可見性**：送出後分數與解析立即顯示，無需切換頁面。
- **一致性**：題型、選項、解析區塊皆統一設計。
- **錯誤預防與回饋**：未作答會明確顯示，錯誤原因與建議清楚列出。
- **極簡設計**：扁平化配色、留白、字體大小分明，資訊層級清楚。
- **即時反饋**：每題解析即時展開，分數與建議一目了然。
- **響應式設計**：確保手機、平板、桌機皆適用。
